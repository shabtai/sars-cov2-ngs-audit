Critical C1: Sample-Level Data Leakage in ML Pipeline Verified

class_model_workflow.ipynb — cells 5, 7–8

train_test_split(X, y, random_state=7, train_size=0.8, stratify=y)

The dataset contains 960 rows representing 96 samples × 10 plates. The row-level train/test split means 100% of test samples also appear in the training set. The model memorizes per-sample patterns rather than learning generalizable features.

Verification: 81 of 81 test samples also present in training data.

Fix: Use GroupShuffleSplit with groups=sample.

MetricLeakedFixed (GroupKFold)
AUC0.9340.932
Sensitivity0.7400.735
Specificity0.9710.972
Note: Impact is modest in this case because the signal is consistent across replicates, but the methodology is still invalid. The paper cannot claim generalization from a leaked evaluation.
High C2: log10(0) Produces -Inf, Silently Dropping Data Verified

Fig_4A-B.R — lines 105–107

log10(all_plates_matrix$E_gene + all_plates_matrix$N1_gene + all_plates_matrix$ORF1a)

When all three gene counts are zero, log10(0) returns -Inf. These rows are silently dropped from downstream plots and analysis. 21 rows affected: 5 positive samples, 16 negative.

Line 80 of the same file correctly uses log(x + 1), showing the authors were aware of the issue but applied the fix inconsistently.

High C3: R assign() Bug — S10 Lane Combination Verified

Fig_4A-B.R — line 64

assign(paste0(unique(all_plates$plate)[i]), "_combined", temp)

The comma is outside paste0(), so "_combined" is passed as the envir argument to assign() instead of being concatenated into the variable name. The correct call should be:

assign(paste0("S10", "_combined"), temp)

R silently coerces the string to an environment reference, producing unpredictable behavior.

High C4: X-Axis Label Mismatch in Mutation Plot Verified

Fig4D.R — line 35

X-axis labels are derived from rows where CONSEQU != "Artefact" (13 labels), but the plot itself filters on CONSEQU != "none" (7 genomic positions). This creates 6 phantom x-axis labels for positions 28322–28327 that have no corresponding data points.

Medium C5: Hard-Coded Row Slice [1:88]

Fig4D.R — line 29

read.csv(...)[1:88,]

Hard-coded row index that works for the current CSV but breaks if rows are added, removed, or reordered. The CSV contains trailing empty rows and a comment row that motivated the slice. The correct fix is to filter on non-empty ID values.

Medium C6: RF Cross-Validation on Wrong Split Verified

class_model_workflow.ipynb — cell 19

Random Forest cross-validation runs on X, y (the full 80% training set) instead of X_train, y_train (the 64% training subset). Other models are evaluated on the 16% validation split. This inflates RF performance relative to other classifiers in the comparison.

Medium C7: True Test Set Never Evaluated Verified

class_model_workflow.ipynb — cell 5

Cell 5 saves a held-out 20% test set. All subsequent model evaluations use the validation split from the remaining 80%. The true test set is never loaded or evaluated anywhere in the notebook. The reported metrics are all validation metrics, not test metrics.

Low C10: Compositional Normalization Mislabeled as TPM

class_model_workflow.ipynb

Gene counts are divided by the sum of 4 genes, creating a constant-sum constraint (compositional data). The resulting ratios are labeled "tpm_ratio" but are not transcripts-per-million. True TPM requires gene-length normalization across the full transcriptome, not 4 targets.

The compositional constraint slightly reduces AUC because it introduces spurious negative correlations between gene ratios, but the practical impact is small with only 4 features.

Factual Data Errors

7 findings
High F1–F6: CONSEQU Annotation Errors at N-Gene Positions 28322–28327 Verified

Six genomic positions have their CONSEQU field set to "none" when they should be annotated as missense or synonymous mutations. All six originate from barcode BD0086 (artefact).

POS REF > ALT Current Correct Codon Confidence
28322 T > A none Missense (Phe → Ile) N codon 17, pos 1 High
28323 T > A none Missense (Phe → Tyr) N codon 17, pos 2 High
28324 T > A none Missense (Phe → Leu) N codon 17, pos 3 High
28325 G > C none Missense (Gly → Arg) N codon 18, pos 1 High
28326 G > C none Missense (Gly → Ala) N codon 18, pos 2 High
28327 T > A none Synonymous (Gly → Gly) N codon 18, pos 3 High

All six positions have mapping quality MQ = 42–45, notably lower than the MQ = 59–60 observed at non-artefact positions. 42 total rows are affected across all plates.

Critical F7: BD0086 Systematic Artefact — Undisclosed Verified

Barcode 86 (BD0086) produces false variant calls across all plates in the study. These artefact calls have consistently lower mapping quality (MQ 42–45 vs. 59–60 for genuine variants) and cluster at N-gene positions 28322–28327.

A comment in the source CSV confirms the issue:

# Barcode 86 produces an artefact call.

This systematic barcode-specific artefact is not discussed anywhere in the paper. For a study whose central contribution is a barcoding methodology, the omission of a known barcode failure mode is a material gap. The artefact affects variant calling accuracy and could mislead researchers applying the same barcoding scheme.
